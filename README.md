## Why single file

Because a demo you have to install is a demo nobody runs.

Every file here opens in a browser by double clicking it. No package manager, no bundler,
no lockfile that rots in six months. View source is the documentation.

## Run it locally

```bash
git clone https://github.com/Pallarium/labs
cd labs
```

Open `index.html` for the gallery, or open any `demos/<name>/index.html` directly.
No server needed.
